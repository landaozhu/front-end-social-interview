> 来源: https://juejin.cn/post/7271092862849794105

去哈啰面试前端开发，面试官告诉我，作为三年前端，不仅要知道怎么用，还得知道怎么实现。于是看到一个api，我就习惯性的想研究研究底层怎么实现。


所谓可选链，就是



```hljs js code-block-extension-codeShowNum
const lwp={
    name:'兰为鹏',
    cat:{
        name:'白芍',
        gender:'小母猫'
    }
}
console.log(lwp?.cat?.name)//白芍
console.log(lwp?.cat?.age)//undefined
```


而不报错。


那如何实现，其实有很多种方法



## 实现



### 



```hljs js code-block-extension-codeShowNum
function get(obj, str) {
  if (!obj) return;
  const arr = str.split(".");
  let res = obj;
  for (let i = 0; i < arr.length; i++) {
    if (res[arr[i]] != null) {
      res = res[arr[i]];
    } else {
      return undefined;
    }
  }
  return res;
}
console.log(get(lwp,'cat.age'))//undefined
console.log(get(lwp,'cat.name'))//白芍
```


用reduce实现也行



```hljs js code-block-extension-codeShowNum
function get(obj, str) {
  if (!obj) return;
  const arr = str.split(".");
  return arr.reduce((o, k) => {
    return (o || {})[k];
  }, obj);
}
```
