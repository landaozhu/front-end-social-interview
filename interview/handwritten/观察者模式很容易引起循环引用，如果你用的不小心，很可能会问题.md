# 观察者模式很容易引起循环引用，如果你用的不小心，很可能会问题

> 来源: https://juejin.cn/post/7270867067216625703

观察者模式和发布订阅模式是两个模式，网上绝大部分文章都会将两者认为是一个模式，混淆两者的特性，甚至书上也把这两个模式混为一谈


我在学习观察者模式的优缺点时发现这么一句话


> 如果观察者和被观察者之间有循环依赖，观察目标会触发它们之间进行循环调用，可能导致系统崩溃


一时间没想出来怎么让它导致循环引用。
现在我们先来实现一个观察者模式。


首先实现两个父类：Observered被观察者，Observer观察者



```hljs js code-block-extension-codeShowNum
/**
 * 被观察者
 * observers 观察者列表
 * add 添加观察者
 * remove 移除观察者
 * notify 通知到所有的观察者
 */
class Observed {
  constructor() {
    this.observers = [];
  }
  add(observer) {
    this.observers.push(observer);
  }
  remobe(observer) {
    this.observers.filter((item) => item === observer);
  }
  notify() {
    this.observers.forEach((item) => item.update(this));
  }
}
```



```hljs js code-block-extension-codeShowNum
/**
 * 观察者
 * 更新
 */
class Observer {
  constructor() {}
  update() {}
}
```


然后根据下面的需求，实现子类，子类继承父类


需求：
产品和UI、开发、测试进行第二版功能开发，其他成员都在等产品的prd文档修改，等修改完成之后，开始进展各自的工作



```hljs js code-block-extension-codeShowNum
class PM extends Observed {
  constructor() {
    super();
    this.prd = "第一版";
  }
  getPrd() {
    return this.prd;
  }
  updatePrd(prd) {
    this.prd = prd;
    this.notify();
  }
}
class RD extends Observer {
  constructor() {
    super();
    this.prd = null;
  }
  update(pm) {
    this.prd = pm.getPrd();
    this.work();
  }
  work() {
    console.log(`拿着${this.prd}进行开发`);
  }
}
class UI extends Observer {
  constructor() {
    super();
    this.prd = null;
  }
  update(pm) {
    this.prd = pm.getPrd();
    this.work();
  }
  work() {
    console.log(`拿着${this.prd}进行设计视觉稿`);
  }
}
const xiaoli = new PM();
const xiaohong = new UI();
const xiaoming = new RD();
xiaoli.add(xiaohong);
xiaoli.add(xiaoming);
xiaoli.updatePrd("第二版");
xiaoli.updatePrd("第三版");
```


那好，如何实现循环引用导致崩溃
在被观察者的父类里面



```hljs js code-block-extension-codeShowNum
notify() {
    this.observers.forEach((item) => item.update(this));
}
```


向被观察者的update方法传入this，这样在观察者里面就能拿到被观察者的状态，例如这里的prd文档
那我们如果在观察者里的update函数调用被观察者的notify方法，而notify又再一次调用观察者的update，最终调用栈崩溃。



```hljs js code-block-extension-codeShowNum
update(pm) {
    this.prd = pm.getPrd();
    this.work();
    // pm.notify();循环引用
  }
```
