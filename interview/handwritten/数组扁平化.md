# 数组扁平化

以下内容整理自本仓库历史讨论稿。

```js
const a = [1, [2, [3, 453, 5, 5]]];
```

## 方法一

```javascript
const Flatten = (arr) => {
  let res = [];
  for (let i = 0; i < arr.length; i++) {
    if (Array.isArray(arr[i])) {
      res = res.concat(Flatten(arr[i]));
    } else {
      res.push(arr[i]);
    }
  }
  return res;
};
```

## 方法二

```javascript
const Flatten = (arr) =>
  Array.isArray(arr) ? arr.reduce((a, b) => [...a, ...Flatten(b)], []) : [arr];
```
