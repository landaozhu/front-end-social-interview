幻觉是模型生成了 **听起来通顺、但与事实或给定资料不符** 的内容。它不是 bug 开关，是语言模型「按概率续写」的副作用：没有检索、没有工具时，它仍会把句子写完。

## 常见类型

- **事实幻觉**：时间、数字、人名错
- **引用幻觉**：编论文、编 URL、编「资料第 3 段」
- **工具幻觉**：假装调了 API，或编造 observation
- **指令幻觉**：你让它只根据资料答，它忽略资料

## 怎么压（面试按层次说）

1. **Prompt**：不会就说不会；禁止编 URL；要求引用 chunk。
2. **RAG**：把证据塞进上下文，并检查答案是否能在资料里找到支撑。
3. **Tool**：实时事实走 API，不要让模型背天气和股价。
4. **解码**：适当降 `temperature`；结构化输出减少格式胡编。
5. **校验**：规则、引用回溯、二次模型做事实检查。
6. **产品**：关键操作人工确认，UI 标明「可能不准确」。

做不到「零幻觉」。25k 要的是 **你知道它必然出现，以及在链路哪一层拦**。

## 面试 60 秒

幻觉是续写本质带来的一本正经胡说。降它靠约束 Prompt、检索给证据、事实走工具、降温度、事后校验，而不是指望换一个从不撒谎的模型。Agent 还要防「假装调了 tool」。

## 追问

**温度调到 0 就没有幻觉了？**

没有。温度只影响随机性，训练语料里的错误和知识截止仍在。0 更稳、更重复，不是更真。

**如何评测？**

抽样人工看；自动看「答案 span 是否出现在检索文档」；工具题对真实 API 结果。不要只看 BLEU。
