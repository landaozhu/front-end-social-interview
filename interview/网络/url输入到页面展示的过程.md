# URL 输入后发生了什么

以下内容整理自本仓库历史讨论稿（原文笔误「dnc」已改为「DNS」）。

## 简要流程

1. 先看有没有缓存：浏览器缓存 → 系统缓存。
2. 没有缓存则用 **DNS** 查询 URL 对应的 IP 地址，再访问该 IP。
3. 建立 TCP 连接。
4. 服务端接收到 HTTP 请求，查库、读写文件、拼接 HTTP 响应。
5. 浏览器接收到首页 HTML。
6. 解析 HTML，形成 DOM Tree。
7. 解析 CSS，形成 CSS Tree。
8. 加载 JS 文件并执行 JS。

## 说明

实际面试中可再补充：TLS 握手（HTTPS）、HTTP/2 多路复用、解析与渲染主路径、合成层与绘制等，按岗位深度展开即可。
