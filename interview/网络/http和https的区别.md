# HTTP 和 HTTPS 的区别

以下内容整理自本仓库历史讨论稿（表格稿）。

| 对比项     | HTTP       | HTTPS        |
| ---------- | ---------- | ------------ |
| 默认端口   | 80         | 443          |
| 数据传输   | 明文传输   | 加密传输     |
| 协议分层表述（常见说法） | 常描述为偏应用层侧 | 常描述为在传输安全之上承载 HTTP |
| 地址协议   | `http://`  | `https://`   |
| 证书       | 不需要证书 | 需要合法证书链（由 CA 签发等） |
| 被劫持风险 | 相对较高   | 显著降低（仍依赖实现与配置）   |
| 站点身份   | 易被仿冒页面诱导 | 配合 OV/EV 等证书可增强站点身份展示（如部分 EV 站点名称展示） |

补充：HTTPS = HTTP + 加密 + 身份校验 + 完整性保护（TLS）；细节可与 [HTTPS 加密过程](./https加密过程.md) 对照阅读。
