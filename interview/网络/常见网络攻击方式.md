# 常见网络攻击方式有哪些？怎么防？

【一句话】前端常考 **XSS、CSRF、点击劫持、中间人**。核心是：**别信用户输入，别让浏览器拿着你的身份乱发请求，传输要加密。**

## XSS（跨站脚本）

恶意脚本跑在你的站点上下文里：偷 cookie、改页面、冒充用户发请求。

| 类型 | 要点 |
|---|---|
| 反射型 | 恶意代码在 URL，点一下才中 |
| 存储型 | 写入库，谁打开页面谁中，最危险 |
| DOM 型 | 前端自己 `innerHTML` / 改 `location` 拼出来的 |

防：输出编码、CSP、`HttpOnly` cookie、不用 `innerHTML` 拼用户内容、富文本白名单。

## CSRF（跨站请求伪造）

用户已登录目标站，攻击站诱导浏览器**自动带 cookie** 发请求。

防：SameSite cookie、CSRF token、关键操作二次验证、别用 cookie 当唯一凭证（改 token 放 header）。

## 点击劫持

iframe 套你的页面，透明按钮盖在上面。防：`X-Frame-Options` / CSP `frame-ancestors`。

## 中间人

HTTP 明文被窃听、篡改。防：HTTPS、HSTS、别忽略证书错误。

## 追问

- **XSS vs CSRF？** XSS 是脚本在你页面里执行；CSRF 不需要执行脚本，是借用你的登录态。XSS 拿到 cookie 后 CSRF 防御也会垮（所以 HttpOnly）。
- **cookie 存 token？** 可以，但必须 HttpOnly + SameSite；XSS 仍可能走同源接口。更常见是内存/header 里放 access token。
