# 15.6.2
## 一、 挂载阶段（Mounting）
组件第一次被插入 DOM 中时调用：getDefaultProps（使用 React.createClass 时）或 constructor：初始化组件的默认属性和状态。

componentWillMount：组件挂载到 DOM 之前调用。在此阶段调用 setState 不会触发重新渲染。

render：返回组件的 JSX 结构，生成虚拟 DOM。

componentDidMount：组件挂载到 DOM 后立即调用。适合进行异步请求、DOM 操作或订阅事件。
## 二、 更新阶段（Updating）
当组件的 props 或 state 发生变化时触发更新：

componentWillReceiveProps(nextProps)：当父组件传入新的 props 时触发。在此可以比较 this.props 和 nextProps，并调用 setState。

shouldComponentUpdate(nextProps, nextState)：决定组件是否需要重新渲染。返回 true 继续，返回 false 则中断更新。用于性能优化。

componentWillUpdate(nextProps, nextState)：组件更新前调用，在此阶段不能调用 setState。render：重新渲染生成新的虚拟 DOM。

componentDidUpdate(prevProps, prevState)：组件更新完成后调用，可在此获取更新后的 DOM 或进行网络请求。
## 三、 卸载阶段（Unmounting）
组件从 DOM 中移除时调用：componentWillUnmount：组件卸载和销毁之前调用。常用于清理定时器、解绑事件监听器或取消未完成的网络请求。如需深入了解各个周期的具体使用场景，可以参考 React 旧版官方文档。
