### 使用异步组件： 将较大的组件分割成异步组件，按需加载，减少初始包的体积。使用 v-if 和 v-for 的最佳实践： 避免在同一个元素上同时使用 v-if 和 v-for，优先使用 computed 或 filter 处理数据。合理使用 keep-alive： 缓存组件实例，避免频繁销毁和创建。减少 Watcher 数量： 尽量减少不必要的响应式数据和复杂的 watch 逻辑。懒加载图片和资源： 对较大的图片资源使用懒加载技术，减少初始渲染压力。使用 Webpack 的代码分割和 Tree Shaking： 优化打包输出，去除未使用的代码。

### 当组件状态或属性发生变化时，React 会生成一个新的虚拟 DOM 树。然后，React 将新旧虚拟 DOM 树进行对比（称为**“diffing”**），找出需要更新的部分。最后，React 将这些变化应用到实际的 DOM 中，从而减少了直接操作 DOM 带来的性能开销。

### 回答要点：Webpack 的构建流程包括以下几个阶段：初始化：读取配置文件，合并默认配置，创建 Compiler 实例。编译：从入口文件开始，递归地解析模块依赖关系。构建模块：对每个模块使用对应的 Loader 进行转换。代码生成：将每个模块的代码转换为浏览器可运行的代码块。输出：将所有代码块输出到文件系统中。

### 回答要点：Webpack 使用 WebSocket 与开发服务器通信，当检测到源代码变化时，Webpack 只更新变化的模块而不刷新页面。HMR 插件会替换旧模块为新模块。

### Webpack 通过 acorn 解析源代码，生成 AST（抽象语法树），遍历 AST 来找出 import 和 require 的依赖，从而建立模块依赖图。

### Plugin 关键点：利用 compiler 对象注册钩子。在合适的钩子中执行自定义逻辑。可以通过 compilation 对象操作构建的文件内容、模块等。Loader 关键点：Loader 函数可以同步返回结果，也可以通过 this.async() 进行异步操作。可以通过 this.query 访问 Loader 的配置选项。多个 Loader 会按照从右到左的顺序链式调用。扩展功能Plugin：可以监听各种钩子来做复杂的构建优化、生成额外文件、修改输出内容等。Loader：可以处理不同类型的文件（如 .css、.jsx），可以转换、编译、压缩代码等。

### 二叉树的 最大深度 是指从根节点到最远叶子节点的最长路径上的节点数。输入：root = [3,9,20,null,null,15,7]
输出：3给定一个二叉树 root ，返回其最大深度。
