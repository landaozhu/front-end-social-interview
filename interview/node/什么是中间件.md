          中间件是位于 HTTP 请求和最终业务处理之间的一层可复用处理函数。

比如日志、鉴权、权限校验、异常处理、跨域等逻辑，很多接口都需要。如果全部写进 Controller，会造成大量重复代码，所以可以把这些横切逻辑抽成独立中间件。

在 Koa 中，中间件本质上就是一个 (ctx, next) => {} 函数，ctx 表示当前请求上下文，next 用来把控制权交给下一个中间件。


横切逻辑抽出去这点对：鉴权、日志、跨域、上传，避免每个接口写一遍。Koa 里就是 (ctx, next) => {}。next 不是「等返回」，是把控制权交给下一个中间件；后面的跑完，还会回到你 await next() 的后面，所以叫洋葱：进的时候一层层往里，出的时候一层层往外。

追问：某个中间件里不调用 next() 会怎样？await next() 前后分别适合做什么？
不调 next() 是短路：后面的中间件根本不会跑，请求在这一层结束（鉴权失败常这么干）。await next() 之前做进入时逻辑（鉴权、打日志），之后做返回时逻辑（改响应头、记耗时）。
