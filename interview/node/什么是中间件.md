          中间件是位于 HTTP 请求和最终业务处理之间的一层可复用处理函数。

比如日志、鉴权、权限校验、异常处理、跨域等逻辑，很多接口都需要。如果全部写进 Controller，会造成大量重复代码，所以可以把这些横切逻辑抽成独立中间件。

在 Koa 中，中间件本质上就是一个 (ctx, next) => {} 函数，ctx 表示当前请求上下文，next 用来把控制权交给下一个中间件。
