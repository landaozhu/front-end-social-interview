# 插入排序（Insertion Sort）

插入排序又分为 **直接插入** 和优化后的 **折半插入**、希尔排序。通常说的插入排序指直接插入。

## 直接插入

打牌时每摸一张新牌，就在已整理好的牌里找到位置插进去。

工作原理：构建有序序列；对未排序数据，在已排序区间从后向前扫描，找到位置并插入。

步骤：

1. 第一个元素视为已排序
2. 取出下一个元素，在已排序区间从后向前扫描
3. 已排序元素大于新元素，就后移一位
4. 重复直到找到 ≤ 新元素的位置
5. 插入
6. 重复 2～5

```js
const insertionSort = (array) => {
  const len = array.length;
  if (len <= 1) return array;

  for (let i = 1; i < len; i++) {
    let preIndex = i - 1;
    const current = array[i];
    while (preIndex >= 0 && array[preIndex] > current) {
      array[preIndex + 1] = array[preIndex];
      preIndex--;
    }
    if (preIndex + 1 !== i) {
      array[preIndex + 1] = current;
    }
  }
  return array;
};
```

分析：

- **原地**：只需常量临时空间，空间 O(1)
- **稳定**：相等元素插到已出现元素后面，相对顺序不变
- **时间**：最好 O(n)（已正序）；最坏 / 平均 O(n²)（反序最坏）

## 折半插入

已排序区间有序，不必逐个找插入点，用二分比较中间值。

步骤：

1. 取 `0 ~ i-1` 中点 `m = (i-1) >> 1`，`array[i]` 与 `array[m]` 比大小，缩小到左半或右半
2. 重复直到找到插入位置
3. 插入点之后的元素全部后移
4. 插入第 i 个元素

`x >> 1` 等于 `Math.floor(x / 2)`。

```js
const binaryInsertionSort = (array) => {
  const len = array.length;
  if (len <= 1) return array;

  for (let i = 1; i < len; i++) {
    let low = 0;
    let high = i - 1;
    const current = array[i];

    while (low <= high) {
      const m = (low + high) >> 1;
      if (array[i] >= array[m]) {
        low = m + 1; // 值相同走高半区，保证稳定
      } else {
        high = m - 1;
      }
    }
    for (let j = i; j > low; j--) {
      array[j] = array[j - 1];
    }
    array[low] = current;
  }
  return array;
};
```

折半插入每次移动的是相邻且值不同的元素，不改变相同值的相对顺序，**稳定**。
