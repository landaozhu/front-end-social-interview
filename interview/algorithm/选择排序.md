# 选择排序（Selection Sort）

也分已排序区间和未排序区间。每次从未排序区间找最小元素，放到已排序区间末尾。

步骤：

1. 在未排序序列里找最小（大）元素，放到排序序列起始位置
2. 再从剩余未排序元素里找最小（大），放到已排序末尾
3. 重复直到全部排完

```js
const selectionSort = (array) => {
  const len = array.length;
  for (let i = 0; i < len - 1; i++) {
    let minIndex = i;
    for (let j = i + 1; j < len; j++) {
      if (array[j] < array[minIndex]) {
        minIndex = j;
      }
    }
    const temp = array[i];
    array[i] = array[minIndex];
    array[minIndex] = temp;
  }
  return array;
};
```

分析：

- **原地**：空间 O(1)
- **不稳定**：每次把未排序最小值和前面元素交换，可能打乱相等元素顺序
- **时间**：无论正序逆序都要扫约 n²/2 次。最好 / 最坏 / 平均都是 O(n²)
