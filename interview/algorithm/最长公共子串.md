# 最长公共子串

两个字符串里 **连续相等** 的最长那段。`raven` 和 `havoc` → `av`。

这是字符串 DP，不是暴力三重循环。25k 要写状态和转移。

## 状态

`dp[i][j]`：以 `str1[i-1]`、`str2[j-1]` **结尾** 的公共子串长度。

## 转移

- `str1[i-1] === str2[j-1]` → `dp[i][j] = dp[i-1][j-1] + 1`
- 否则 → `dp[i][j] = 0`（子串必须连续，断了就归零）

扫表时记下最大长度和结束下标，再 `slice` 出来。

```js
function maxSubString(str1, str2) {
  if (!str1 || !str2) return '';
  const n = str1.length;
  const m = str2.length;
  const dp = Array.from({ length: n + 1 }, () => Array(m + 1).fill(0));
  let maxLen = 0;
  let end = 0;

  for (let i = 1; i <= n; i++) {
    for (let j = 1; j <= m; j++) {
      if (str1[i - 1] === str2[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1] + 1;
        if (dp[i][j] > maxLen) {
          maxLen = dp[i][j];
          end = i;
        }
      }
    }
  }
  return str1.slice(end - maxLen, end);
}
```

时间 O(n × m)，空间 O(n × m)。

注意：最长公共 **子序列** 是可以断开的，转移不同，别混。

暴力枚举起点再向后匹配能出结果，但不是这题要练的方法。
