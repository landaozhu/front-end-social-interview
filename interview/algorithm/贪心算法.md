# 贪心算法

每一步只选当下看起来最好的，不回头。一串局部最优如果能推出整体最优，贪心就是对的；否则只是近似。比动态规划便宜，但不是所有题都能用。

## 部分背包

背包容量有限。每件物品有重量、价值，**可以切开按比例装**（金粉、布匹）。求装进去的总价值最大。

和 [0-1 背包](./背包问题.md) 的唯一差别：0-1 只能整件带走或留下；这里能装半件。

例：重量 `[10, 20, 30]`，价值 `[60, 100, 120]`，容量 50。

先算性价比（价值 / 重量）：

```
金  60/10 = 6
银 100/20 = 5
铜 120/30 = 4
```

贪心：性价比从高到低装，一种装完或背包装满再看下一种。

```
容量 50
1. 金性价比最高，10 全装得下 → 价值 60，已用 10，剩 40
2. 银 20 全装得下           → 价值再加 100，已用 30，剩 20
3. 铜要 30，只剩 20，装 20/30
     价值再加 120 × (20/30) = 80
合计 60 + 100 + 80 = 240
```

最后一件按比例切，所以贪心是对的：同等重量，先装单价高的一定不亏。

同样这组数如果改成 0-1（不能切），按性价比会拿走金+银=160，但银+铜=220 更好。不能切时贪心会错，要用 DP。

```js
function knapsack(capacity, objectArr) {
  // 性价比从高到低。注意：会改原数组顺序
  objectArr.sort((a, b) => b.value / b.size - a.value / a.size);

  let selected = 0; // 已经占用的容量
  let maxValue = 0;

  for (let i = 0; i < objectArr.length && selected < capacity; i++) {
    const { size, value } = objectArr[i];
    const remain = capacity - selected; // 还剩多少空间

    if (size <= remain) {
      // 整件放得下，全拿走
      maxValue += value;
      selected += size;
    } else {
      // 放不下整件：只装 remain/size 这么多，背包装满后结束
      maxValue += value * (remain / size);
      selected = capacity;
    }
  }

  return maxValue;
}

// knapsack(50, [
//   { size: 10, value: 60 },
//   { size: 20, value: 100 },
//   { size: 30, value: 120 },
// ]) === 240
```
