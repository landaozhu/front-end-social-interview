# 贪心算法

动态规划能优化递归得到的次优方案，但对很多问题大材小用。贪心总是选当下最优，不管这次选择会不会坑后面。若一系列局部最优能推出整体最优，就得到最优解，否则是次优解。很多问题求最优太贵，贪心够用。

## 部分背包

物品可以按比例装（布匹、金粉），就能贪心：按 **单价 / 单位体积** 从高到低装，一种装完或背包装满再装下一种。这叫部分背包。

0-1 背包不能贪心：不能装「半台电视」。离散物品必须整件选或不选，见 [背包问题](./背包问题.md)。

```js
function knapsack(capacity, objectArr) {
  objectArr.sort((a, b) => b.value / b.size - a.value / a.size);
  let selected = 0;
  let maxValue = 0;
  for (let i = 0; i < objectArr.length && selected < capacity; i++) {
    const { size, value } = objectArr[i];
    if (size <= capacity - selected) {
      maxValue += value;
      selected += size;
    } else {
      maxValue += value * ((capacity - selected) / size);
      selected = capacity;
    }
  }
  return maxValue;
}
```
