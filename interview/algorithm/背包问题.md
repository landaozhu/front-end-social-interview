# 0-1 背包问题

保险箱里有若干宝贝，背包容量有限，每件物品要么带走要么留下，求总价值最大。

例：尺寸 `[3,4,7,8,9]`，价值 `[4,5,10,11,13]`，容量 16。最优是第 3 件 + 第 5 件，尺寸 16，价值 23。

「0-1」含义：每件物品选或不选，不能拆。5 件就是 2^5 种组合，件数一多就枚举不完。

## 为什么是二维数组

贪心按「价值/重量」排序会错（不能拆开装）。能用的办法是：物品一件件考虑，每件只问「选还是不选」。

问题在于：单独看「第 i 件」不够。第 3 件重 7、值 10，但你不知道前面已经占了多少容量。物品抢同一块空间，必须记住两件事：

1. **已经考虑过哪些物品** —— 给物品编号 1～n，规定每次多看一件，写成「前 i 件」（不是「只有第 i 件」）
2. **当前还有多少容量** —— 写成 w

少一维都推不下去。所以用一张表，一行一个前缀、一列一个容量，格子里只存一个数：最大价值。

`f[i][w]` = 只在前 i 件里选、容量**不超过** w 时的最大价值。

原题 5 件、容量 16，表就是 6 行 × 17 列（多一行一列给「0 件 / 容量 0」当起点）：

```
              容量 w →
           0   1   2  ...  16
前 0 件    0   0   0       0     ← 没有物品，价值全是 0
前 1 件    0              f[1][16]
前 2 件    0              f[2][16]
前 3 件    0              f[3][16]
前 4 件    0              f[4][16]
前 5 件    0              f[5][16]  ← 所求：5 件都考虑完、容量 16
```

- `f[0][16] = 0`：一件都还没看，空背包，价值 0（第 0 行无论哪一列都是 0）
- `f[i][0] = 0`：容量为 0，什么都装不下
- 编号只是顺序，换个编号最终 `f[5][16]` 一样；每件只出现在一行里，所以每件最多选一次

程序从上到下、从左到右把整张表填满。手算只写用得到的格子。

## 一格怎么填

填 `f[i][w]` 时，第 i 件只有两个选择，答案都在**上一行**（前 i-1 件已经算完）：

- **不选**：容量没变，抄 `f[i-1][w]`
- **选**：先扣掉这件重量 `w[i]`，去上一行找「剩下的容量」那一列，再加上这件的价值 `v[i]`  
  也就是 `f[i-1][w - w[i]] + v[i]`。放不下（`w[i] > w`）就只能不选。

两选一，取大的：

```
f[i][w] = max{ f[i-1][w], f[i-1][w - w[i]] + v[i] }
           │              │
           │              └ 选：跳到上一行、更靠左的一列（容量变小了）
           └ 不选：上一行同一列
```

「选」会换列，所以不是只算 w=16 这一列就够。例如选第 5 件（重 9）时，要去查 `f[4][16-9]`，也就是 `f[4][7]`。

下面按原题，从第 1 件推到第 5 件，主线都在容量 16；需要换列时再算那一格。

```
第 1 件 重3 值4，w=16
  不选 = f[0][16]     = 0
  选   = f[0][16-3]+4 = 4
  → f[1][16] = 4                    // 只带第 1 件

第 2 件 重4 值5，w=16
  不选 = f[1][16]      = 4          // 只带第 1 件
  选   = f[1][16-4]+5  = 4+5 = 9    // 第 1+第 2 件
  → f[2][16] = max(4, 9) = 9

第 3 件 重7 值10，w=16
  不选 = f[2][16]      = 9          // 第 1+第 2 件
  选   = f[2][16-7]+10 = 9+10 = 19  // 前 3 件全带：3+4+7=14
  → f[3][16] = max(9, 19) = 19

第 4 件 重8 值11，w=16
  不选 = f[3][16]      = 19         // 前 3 件全带
  选   = f[3][16-8]+11 = f[3][8]+11
       f[3][8]：容量 8 只放得下第 3 件（重7 值10）→ 10
       10+11 = 21                   // 第 3+第 4 件：7+8=15
  → f[4][16] = max(19, 21) = 21

第 5 件 重9 值13，w=16
  不选 = f[4][16]      = 21         // 第 3+第 4 件
  选   = f[4][16-9]+13 = f[4][7]+13
       7 是 16-9：带走第 5 件后剩下的容量
       f[4][7]：第 4 件重 8 放不进 7；第 3 件刚好 7 值 10 → 10
       10+13 = 23                   // 第 3+第 5 件：7+9=16
  → f[5][16] = max(21, 23) = 23
```

## 递归（会重复计算同一格子）

```js
function knapsack(capacity, objectArr, order) {
  if (order < 0 || capacity <= 0) return 0;
  if (objectArr[order].size > capacity) {
    return knapsack(capacity, objectArr, order - 1);
  }
  return Math.max(
    objectArr[order].value + knapsack(capacity - objectArr[order].size, objectArr, order - 1),
    knapsack(capacity, objectArr, order - 1),
  );
}
```

## 按表填：二维 DP

代码里 `i === 0 || w === 0` 就是上面那张表的第 0 行和第 0 列。`objectArr[i - 1]` 是因为数组下标从 0 起，对应「第 i 件」。

```js
function knapsack(capacity, objectArr) {
  const n = objectArr.length;
  const f = [];
  for (let i = 0; i <= n; i++) {
    f[i] = [];
    for (let w = 0; w <= capacity; w++) {
      if (i === 0 || w === 0) {
        f[i][w] = 0;
      } else if (objectArr[i - 1].size <= w) {
        const { size, value } = objectArr[i - 1];
        f[i][w] = Math.max(f[i - 1][w - size] + value, f[i - 1][w]);
      } else {
        f[i][w] = f[i - 1][w];
      }
    }
  }
  return f[n][capacity];
}
```

时间 / 空间 O(n × 容量)。填 `f[i]` 时只用上一行 `f[i-1]`，所以可以压成一维，一行容量反复覆盖：

```
f[w] = max{ f[w], f[w - w[i]] + v[i] }
```

必须从大到小更新 w：先算大容量，再用还没被本件改过的 `f[w - w[i]]`（那仍是上一件的结果）。从小到大会把同一件用两次，变成完全背包。

物品不能拆时不能用贪心，见 [贪心算法](./贪心算法.md)。
