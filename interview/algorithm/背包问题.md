# 0-1 背包问题

保险箱里有若干宝贝，背包容量有限，每件物品要么带走要么留下，求总价值最大。

例：尺寸 `[3,4,7,8,9]`，价值 `[4,5,10,11,13]`，容量 16。最优是第 3 件 + 第 5 件，尺寸 16，价值 23。

「0-1」含义：每件物品选或不选，不能拆。

状态：`f[i][w]` = 前 i 件物品、容量恰好为 w 时的最大价值。

转移：

```
f[i][w] = max{ f[i-1][w], f[i-1][w - w[i]] + v[i] }
```

递归（会重复计算）：

```js
function knapsack(capacity, objectArr, order) {
  if (order < 0 || capacity <= 0) return 0;
  if (objectArr[order].size > capacity) {
    return knapsack(capacity, objectArr, order - 1);
  }
  return Math.max(
    objectArr[order].value + knapsack(capacity - objectArr[order].size, objectArr, order - 1),
    knapsack(capacity, objectArr, order - 1),
  );
}
```

DP 二维：

```js
function knapsack(capacity, objectArr) {
  const n = objectArr.length;
  const f = [];
  for (let i = 0; i <= n; i++) {
    f[i] = [];
    for (let w = 0; w <= capacity; w++) {
      if (i === 0 || w === 0) {
        f[i][w] = 0;
      } else if (objectArr[i - 1].size <= w) {
        const { size, value } = objectArr[i - 1];
        f[i][w] = Math.max(f[i - 1][w - size] + value, f[i - 1][w]);
      } else {
        f[i][w] = f[i - 1][w];
      }
    }
  }
  return f[n][capacity];
}
```

时间 / 空间 O(n × m)。空间可压到 O(m)：

```
f[w] = max{ f[w], f[w - w[i]] + v[i] }
```

物品不能拆时不能用贪心，见 [贪心算法](./贪心算法.md)。
