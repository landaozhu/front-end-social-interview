# 桶排序（Bucket Sort）

计数排序的升级版，也用分治。

思想：

1. 把数据分到有限个有序的桶里
2. 每个桶内部再排序（常用插入或快排）
3. 按桶顺序取出，整体就有序

要高效需要：额外空间够就尽量多开桶；映射函数尽量把 N 个数据均匀分到 K 个桶。核心是怎么平均分到桶里。

```js
const bucketSort = (array, bucketSize) => {
  if (array.length === 0) return array;

  let minValue = array[0];
  let maxValue = array[0];
  for (let i = 1; i < array.length; i++) {
    if (array[i] < minValue) minValue = array[i];
    else if (array[i] > maxValue) maxValue = array[i];
  }

  const DEFAULT_BUCKET_SIZE = 5;
  bucketSize = bucketSize || DEFAULT_BUCKET_SIZE;
  const bucketCount = Math.floor((maxValue - minValue) / bucketSize) + 1;
  const buckets = Array.from({ length: bucketCount }, () => []);

  for (let i = 0; i < array.length; i++) {
    buckets[Math.floor((array[i] - minValue) / bucketSize)].push(array[i]);
  }

  array.length = 0;
  for (let i = 0; i < buckets.length; i++) {
    buckets[i].sort((a, b) => a - b);
    for (let j = 0; j < buckets[i].length; j++) {
      array.push(buckets[i][j]);
    }
  }
  return array;
};
```

分析：

- **不是原地**：空间 O(n)
- **稳定性**取决于桶内排序：快排不稳定，归并稳定
- **时间**：桶内排序方式影响大。n 个数据均匀进 m 个桶，每桶 k = n/m。桶内快排则整体 O(n log(n/m))；m 接近 n 时接近 O(n)
  - 最好 O(n)：数据均匀分到各桶
  - 最坏 O(n log n)：全进同一个桶

适用：外部排序（数据在磁盘、内存装不下）。桶越小排得越快，但更占空间。
