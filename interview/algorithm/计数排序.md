# 计数排序（Counting Sort）

思想：

1. 找出最大、最小元素
2. 统计值为 i 的出现次数，写入 `countArr[i]`
3. 对计数做前缀和（每一项加前一项）
4. **反向**填充：把 i 放到 `countArr[i]` 对应位置，每放一个就把计数减 1

关键是理解最后反向填充。可以看成桶排序的特例：范围不大时，每个桶里的值都相同，省掉桶内排序。

使用条件：

- 数据范围 k 不能比 n 大很多
- 只能排非负整数；其他类型要先不改变相对大小地转成非负整数（成绩精确到 0.1 就先 ×10）

```js
const countingSort = (array) => {
  const len = array.length;
  const result = [];
  const countArr = [];
  let min = array[0];
  let max = array[0];

  for (let i = 0; i < len; i++) {
    min = min <= array[i] ? min : array[i];
    max = max >= array[i] ? max : array[i];
    countArr[array[i]] = countArr[array[i]] ? countArr[array[i]] + 1 : 1;
  }

  for (let j = min; j < max; j++) {
    countArr[j + 1] = (countArr[j + 1] || 0) + (countArr[j] || 0);
  }

  for (let k = len - 1; k >= 0; k--) {
    result[countArr[array[k]] - 1] = array[k];
    countArr[array[k]]--;
  }
  return result;
};
```

更简单的写法（按下标直接吐出）：

```js
const countingSort2 = (arr, maxValue) => {
  maxValue = maxValue || arr.length;
  const bucket = new Array(maxValue + 1);
  let sortedIndex = 0;

  for (let i = 0; i < arr.length; i++) {
    bucket[arr[i]] = (bucket[arr[i]] || 0) + 1;
  }
  for (let j = 0; j < bucket.length; j++) {
    while (bucket[j] > 0) {
      arr[sortedIndex++] = j;
      bucket[j]--;
    }
  }
  return arr;
};
```

例子：50 万考生、分数 0～900，开 901 个桶，分数相同的进同一个桶，依次扫桶输出，O(n)。

分析：

- **不是原地**：空间 O(k)，k 是桶个数 / 值域
- **稳定**：不改变相同元素相对顺序（方法一反向填充保证稳定）
- **时间**：最好 / 最坏 / 平均 O(n + k)
