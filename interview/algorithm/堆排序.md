# 堆排序（Heap Sort）

堆是完全二叉树，且每个节点 ≥（或 ≤）其子树所有节点。前者大顶堆，后者小顶堆。

堆的定义见 [堆](../dataStructure/堆.md)。这里只写排序。

思想：

1. 把序列建成大顶堆，作为无序区
2. 堆顶 R[1] 与最后一个 R[n] 交换，有序区多一个最大值
3. 对新无序区重新 heapify，再交换……直到有序区长度为 n-1

```js
const heapSort = (array) => {
  for (let i = Math.floor(array.length / 2 - 1); i >= 0; i--) {
    heapify(array, i, array.length);
  }
  for (let i = array.length - 1; i > 0; i--) {
    swap(array, 0, i);
    heapify(array, 0, i);
  }
  return array;
};

const swap = (array, i, j) => {
  const temp = array[i];
  array[i] = array[j];
  array[j] = temp;
};

// 假定 i 以下子堆已是大顶堆，把 i 沉到正确位置
const heapify = (array, i, length) => {
  for (let j = 2 * i + 1; j < length; j = 2 * j + 1) {
    const temp = array[i];
    if (j + 1 < length && array[j] < array[j + 1]) {
      j++;
    }
    if (temp < array[j]) {
      swap(array, i, j);
      i = j;
    } else {
      break;
    }
  }
};
```

分析：

- **原地**：只需个别临时变量
- **不稳定**：堆顶和最后一个节点互换，可能打乱相等元素顺序
- **时间**：建堆 O(n)，排序 O(n log n)，整体 O(n log n)。最好 / 最坏 / 平均都是 O(n log n)
