# 归并排序（Merge Sort）

把数组从中间分成前后两部分，分别排序，再合并成一个有序数组。采用 **分治**：大问题拆成子问题，子问题解了大问题就解了。

```js
const mergeSort = (arr) => {
  const len = arr.length;
  if (len < 2) return arr;

  const middle = Math.floor(len / 2);
  const left = arr.slice(0, middle);
  const right = arr.slice(middle);
  return merge(mergeSort(left), mergeSort(right));
};

const merge = (left, right) => {
  const result = [];
  while (left.length && right.length) {
    // 必须 <=，只写 < 会不稳定
    if (left[0] <= right[0]) {
      result.push(left.shift());
    } else {
      result.push(right.shift());
    }
  }
  while (left.length) result.push(left.shift());
  while (right.length) result.push(right.shift());
  return result;
};
```

分析：

- **不是原地**：合并两个有序数组要额外空间。任意时刻临时空间不超过 n，空间 O(n)
- **稳定**：`left[0] <= right[0]` 保证相等元素合并前后顺序不变
- **时间**：拆 log n 步，每步合并 O(n)，综合 O(n log n)。最好 / 最坏 / 平均都是 O(n log n)

## 和快排的区别

都是分治，递推公式很像：

- 归并：由下而上，先处理子问题再合并
- 快排：由上而下，先分区再处理子问题
- 归并稳定、O(n log n)，但非原地（合并没法在原地做）
- 快排靠原地分区，解决了归并占内存的问题，但不稳定，最坏会退化成 O(n²)
