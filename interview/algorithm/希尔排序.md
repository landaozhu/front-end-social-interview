# 希尔排序（Shell Sort）

先把待排序列按间隔拆成若干子序列，各自做直接插入；整体基本有序后，再对全体做一次插入排序。

过程（间隔 4 → 2 → 1 的例子 `[35, 33, 42, 10, 14, 19, 27, 44]`）：

1. 间隔 4，虚拟子列 `{35,14}` `{33,19}` `{42,27}` `{10,44}`，各自比较并在原数组里交换
2. 间隔 2，得到两列再排
3. 间隔 1，就是普通插入排序

```js
const shellSort = (arr) => {
  const len = arr.length;
  let gap = 1;
  while (gap < len / 3) {
    gap = gap * 3 + 1; // 动态间隔
  }
  for (; gap > 0; gap = Math.floor(gap / 3)) {
    for (let i = gap; i < len; i++) {
      const temp = arr[i];
      let j = i - gap;
      for (; j >= 0 && arr[j] > temp; j -= gap) {
        arr[j + gap] = arr[j];
      }
      arr[j + gap] = temp;
    }
  }
  return arr;
};
```

分析：

- **原地**：只涉及交换，空间 O(1)
- **不稳定**：单次插入稳定，但多次不同间隔的插入可能改变相等元素相对顺序
- **时间**：最好 O(n log n)；最坏 / 平均约 O(n log² n)
