# 如何分析一个排序算法

复杂度分析是算法学习的精髓。

- **时间复杂度**：算法执行所耗费的时间
- **空间复杂度**：跑完程序所需内存大小

学排序除了原理和代码，更重要的是会评价、分析。从 **执行效率、内存消耗、稳定性** 三方面入手。

## 执行效率

### 最好、最坏、平均时间复杂度

要分别给出三种情况，并说出最好 / 最坏对应的原始数据长什么样。

### 系数、常数、低阶

大 O 表示的是 n 很大时的增长趋势，会忽略系数、常数、低阶。实际开发里经常排 10、100、1000 这种小数据，同阶算法对比时要把这些也算进去。

### 比较次数和交换（或移动）次数

基于比较的排序会涉及：元素比大小、元素交换或移动。分析效率时这两项都要看。

## 内存消耗

看空间复杂度，并分清这些术语：

- **内排序**：全部在内存里完成
- **外排序**：数据太大放磁盘，靠磁盘和内存传输才能排
- **原地排序**：空间复杂度是 O(1) 的排序

## 稳定性

- **稳定**：值相等的元素，排序后相对先后顺序不变
- **不稳定**：值相等的元素，排序后相对先后顺序变了
