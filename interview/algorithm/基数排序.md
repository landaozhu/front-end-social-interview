# 基数排序（Radix Sort）

非比较的整数排序：把整数按位切开，再按每个位分别排。

例子：10 万个手机号。比大小时，前面几位已经能分出胜负后面就不用看。范围太大，桶排序 / 计数排序不合适，基数排序可以做到 O(n)。

使用条件：

- 数据能拆成独立的位来比较
- 位有递进关系：高位已经更大，低位不用看
- 每一位的值域不能太大，要用线性排序，否则整体做不到 O(n)

两种实现：

- **MSD**：从高位开始分组，位数多时适用
- **LSD**：从低位开始排到高位，位数少时适用

```js
const radixSort = (array, max) => {
  const buckets = [];
  let unit = 10;
  let base = 1;
  for (let i = 0; i < max; i++, base *= 10, unit *= 10) {
    for (let j = 0; j < array.length; j++) {
      const index = ~~((array[j] % unit) / base);
      if (buckets[index] == null) buckets[index] = [];
      buckets[index].push(array[j]);
    }
    let pos = 0;
    for (let j = 0; j < buckets.length; j++) {
      if (buckets[j] != null) {
        let value;
        while ((value = buckets[j].shift()) != null) {
          array[pos++] = value;
        }
      }
    }
  }
  return array;
};
```

`max` 是最大位数。从桶底先捞，保证同一桶里先入的排在前面。

分析：

- **不是原地**：空间 O(n + k)
- **稳定**：不改变相同元素相对顺序
- **时间**：最好 / 最坏 / 平均 O(n × k)，k 是位数
