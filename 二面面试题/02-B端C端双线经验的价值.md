# B 端 C 端双线经验有什么价值？

## 30 秒版

B 端懂**供给怎么录**（上单、场次、销售计划、条件退），C 端懂**用户怎么买**（选座、票档、支付）。连起来能判断一个 B 端改动对转化/库存/退改的影响，沟通产品后端更高效，不是只会某一端。

## 2 分钟版

**B 端（范特西）**：商家录项目 → 场次 → 销售计划 → 履约/退改。我做过条件退、蓄水，知道「审核通过 + 定时开售」对 C 端展示和退改规则的影响。

**C 端（选座）**：用户看详情 → 票档/日历 → 选座 → 下单。我做过性能和多场次规则，知道 B 端场次状态如何映射到「可点/不可点」。

**价值举例**  
- B 端改开售时间 → C 端倒计时/可售状态要联动（销售计划 bug 1204583：B 端开倒计时 C 端没展示，字段 1.0/2.0 未对齐）  
- 选座体验差 → 影响商户供给意愿（转正选座背景 For B 端商户）

**对 20k 岗位**：交易型公司需要懂全链路的人，减少「B 端改完 C 端踩坑」。
