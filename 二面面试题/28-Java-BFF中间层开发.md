# Java BFF 中间层开发经验？

## 30 秒版

携程 Trip.com 酒店地图页，前端 React SSR，**Java BFF** 做中间层。我开发过**价格下沉**（价格数据在 BFF 聚合下发）、**地图围栏**（地理范围筛选）等接口，减少前端多次请求，方便 SSR 一次拿齐数据。

## 2 分钟版

**为什么 BFF**  
- 海外酒店：多数据源（价格、库存、地图 POI）  
- 前端 SSR 需要**一次请求拿齐**首屏数据  
- 地图围栏逻辑放 BFF，前端只传坐标/范围参数  

**分工**  
- 我：BFF 接口设计实现 + 前端联调  
- 不是纯 CRUD — 要理解**酒店搜索业务**  

**与猫眼 Egg 对比**  
- 同一模式：**离前端近的聚合层**  
- 技术栈不同（Java vs Egg），思路一致  

**边界**  
- 复杂订单/支付仍核心后端  
- 我负责**地图/价格相关的 BFF 能力**
