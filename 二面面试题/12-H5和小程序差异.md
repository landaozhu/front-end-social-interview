# H5 和小程序开发有什么差异？

## 30 秒版

**环境**：浏览器 vs 微信 JSCore，无 DOM。**体积**：小程序主包 2M 限制 → 分包。**路由**：vue-router vs 页面栈最多 10 层。**登录**：Cookie vs wx.login+code2Session。**渲染**：小程序双线程，setData 有成本。**选座实践**：接口层复用，UI/日历高度/滚动分端适配。

## 2 分钟版

| 维度 | H5 | 微信小程序 |
|------|-----|-----------|
| API | fetch/axios | wx.request，域名白名单 |
| 生命周期 | vue 路由 | onLoad/onShow/onHide |
| 布局 | CSS 灵活 | rpx、安全区、swiper 高度敏感 |
| 性能 | 大包、长任务 | 分包、setData 频率 |
| 发布 | 静态资源+灰度 | 提审、体验版、基础库兼容 |

**选座日历高度**  
- 子组件 query 高度 → 父组件设 swiper — 小程序尤其需要  
- 测试前缀：H5 `m.51ping.com/my/...`，小程序 `m.51ping.com/mysh/...`  

**协作**  
- 共享接口定义和状态机  
- nightly 对核心用例：单场次、多场次、售罄
