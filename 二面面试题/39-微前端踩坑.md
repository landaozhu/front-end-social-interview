# 微前端还有哪些坑？

## 30 秒版

除样式隔离、路由、卸载残留外：**子应用独立部署版本漂移**（主应用引错 entry）、**全局状态滥用**、**公共依赖重复打包**、**主子应用 CSS 变量冲突**。我们主应用严格管 login/menu，子应用禁止改 window；升级后全量测子应用切换。

## 2 分钟版

1. **版本漂移**：子应用发版后主应用缓存旧 entry → 配 nginx 缓存策略 + 版本号  
2. **重复依赖**：vue/antd 若各子应用打包 → 用 externals 或 shared（qiankun 推荐 externals 由主应用 load）  
3. **通信**：禁止随意 eventBus；优先 URL 参数 + 后端业务 id  
4. **鉴权**：token 主应用统一注入，子应用不各自 login  
5. **本地开发**：子应用独立启动 + 主应用 proxy，环境变量 publicPath 一致  
6. **测试**：切换子应用 10 次无 memory leak；条件退 → 销售计划 tab 无脏数据  

**与上单业务**  
- 1.0/2.0 并存期，子应用边界 = 业务域边界，不是页面堆叠
