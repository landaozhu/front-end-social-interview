# 酒店复访功能怎么做的？

## 30 秒版

Trip.com 地图模块上**独立设计开发的复访功能** — 让用户快速回到最近浏览/关注的酒店，缩短决策路径。该功能**明显增加了订单量**（简历结论）。通过 Redux 持久化浏览记录 + 地图/列表入口展示 + 埋点验证转化。

## 2 分钟版

**业务价值**  
- 海外用户决策周期长，复访降低再次搜索成本  
- 产品指标：订单量提升  

**技术要点**  
1. **状态设计**：最近浏览酒店 id 列表，去重、上限  
2. **SSR 兼容**：服务端不读 localStorage，客户端 hydrate 后加载复访列表  
3. **与地图联动**：点击复访项地图定位 + 列表高亮  
4. **质量**：Jest 覆盖核心 reducer；多环境测试  

**面试注意**  
- 若追问细节，强调**独立负责从方案到上线**  
- 用「订单量明显提升」作结果，无精确数字可说 A/B 或产品反馈
