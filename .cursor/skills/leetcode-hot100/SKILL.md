# LeetCode 热题 100（平台自做 · 遗忘曲线）

题单来自 [LeetCode 热题 100](https://leetcode.cn/studyplan/top-100-liked/)。  
进度表：`leetcode热题100.md` / `leetcode热题100.json`。

已通过批次的「首次学会」锚点是 **2026-07-31**（7 月底过完一轮），不是建表当天。

## 怎么考

每次 **只出 1 题**。回复里 **只给题名 + 力扣链接**。

禁止：手写要求、签名、样例、提示、题解、复杂度追问、一次多题。

用户自己去力扣平台写代码。做完后会告诉你通没通过。

## 抽题范围

**只抽已通过（`unlocked`）的题。**  
有「✓ 遗忘」时 **60%** 抽遗忘加练、**40%** 抽其余到期；没有遗忘则全抽到期。  
**当天已经做过的题（通过或没过）当天绝不再抽。**  
未测题先不抽。用户自己做完后说「xx 已经通过」再解锁进池。

## 用户怎么回报 → 怎么写表

| 用户说 | 动作 |
|--------|------|
| 通过 / 已通过 / 过了 | 上次抽出的题：✓，清掉遗忘标记，写入当前 R 节点 |
| 没通过 / 没过 | 上次抽出的题：**保持 ✓**，标 **✓ 遗忘**（提高抽中频率）；**不打 ✗、不清首次学会** |
| **xx 已经通过** / **xx 通过了** | 按题名找到该题：解锁 + ✓ + 写当前 R；不要求这题是刚抽出的 |
| **这题不再提问** / **xx 不再提问** | 上次抽出的题或指定题打「不再提问」；**以后永远不抽**。通过/没过**不会**自动打这钩 |

没过 = 太久没复习忘了，不是从来没学过。

```bash
node .cursor/skills/leetcode-hot100/scripts/pick-question.js
node .cursor/skills/leetcode-hot100/scripts/mark-result.js --pass
node .cursor/skills/leetcode-hot100/scripts/mark-result.js --fail
node .cursor/skills/leetcode-hot100/scripts/mark-result.js --retire
node .cursor/skills/leetcode-hot100/scripts/mark-result.js --pass "两数之和"
node .cursor/skills/leetcode-hot100/scripts/init-questions.js
```

## Agent 流程

1. 抽题：跑 pick。只回复题名（可带简单/中等/困难）和 `path` 链接。
2. 用户说通过/没通过：跑 mark-result，同步 md。回复一句已更新即可。抽题会话里通过后，再抽下一题（仍然只发题名+链接）。
3. 用户主动报「xx 已经通过」：`--pass "xx"`，只更新表，不要另外出题，除非用户同时在要下一题。
4. 用户主动说「这题不再提问」「xx 不再提问」：`--retire` 或 `--retire "xx"`。**不要**因为通过了就自动打。
5. 找不到题名时问一句确认，不要猜错题。

## 禁止

- ❌ 让用户在对话里手写代码
- ❌ 先贴题解 / 提示解法
- ❌ 一次出多题
- ❌ 写进 25k 考察列表（这是独立表）
- ❌ 力扣没过就打 ✗ / 清空首次学会日期
- ❌ 当天已经做过的题（对错都算）再抽一次
- ❌ 已打「不再提问」的题再抽
- ❌ 用户没说「不再提问」就自动打钩
