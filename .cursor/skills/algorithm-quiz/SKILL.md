# 算法抽查（单题手写 · 25k）

只考 `interview/algorithm/` 里能手写的题。每次 **1 题**。

候选人目标：**上海 25k 中大厂前端**。不限一面还是二面，**够 25k 就考**。  
不是算法岗竞赛，也**不要为了「前端」把 DP 降成暴力**。

**只出代码题**。禁止纯口述。复杂度、稳定、原地只能写完再追问。

## 怎么考（25k）

| 题的算法 | 必须写出 | 不要降级成 | 不必加码 |
|----------|----------|------------|----------|
| 排序 | 该排序的 JS | 直接 `arr.sort` | 三路快排、间隔序列证明 |
| 二分 | 二分 JS | 线性扫 | 旋转数组 |
| 递归 / 简单 DP | 递推或带出口的递归 | 无出口瞎递归 | 矩阵快速幂 |
| **字符串 DP / 背包** | **状态 + 转移的 DP 代码** | **暴力多重循环** | 滚动数组、完全背包 |

判分看 `question.method`：`dp` 必须有状态数组/转移；只交暴力 → 不过线。

题池排除：如何分析排序、十大排序对比、高频题汇总（不是单题实现）。

## 抽题

按 25k 出现频率：高频 60% · 中频 30% · 低频 10%。

```bash
node .cursor/skills/algorithm-quiz/scripts/pick-algorithm.js
```

抽到后读 `question.path`。不要把文件或提示提前给候选人。

## 及格线

| 频率 | 及格 | 过线 |
|------|------|------|
| 高频 / 中频 | ≥ **6** | 按 `method` 写出能跑的 JS |
| 低频 | ≥ **5** | 同上 |

没写出可运行代码 → ≤4。DP 题只交暴力 → ≤4。用 `pass` 判，不要用 `skip` 扣分。

## Agent 流程

1. 出编码任务（签名 + 样例）。`method` 为 `dp` 时题目里写明用动态规划。
2. 提示一层一层给：状态定义 → 转移方程 → 骨架。不贴全文。
3. 代码对完再追问复杂度等。
4. 打分。不写 25k 考察表。

## 禁止

- ❌ 把 DP 题改成「暴力就行」
- ❌ 纯概念题
- ❌ 算法竞赛加码
- ❌ 先贴答案 / 一次多题
