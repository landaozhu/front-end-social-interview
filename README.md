# 2026年大厂社招前端面试宝典

## 介绍

这是一个针对大厂社招前端面试宝典。

市面上有很多面经，往往内容不够丰富，容易被挖深就答不出，或者不够新，几年前的很多面试题现在压根不问，本项目针对社招前端，本着快速复习的需求，做了题目和答案的整理。适用于P5、P6，3-5年

解释：1.高频为从上到下，因此阅读此文只需要从上到下，我已排好；2.有些过时的2026年不会再问就没必要学了，所以尽量看最新出的面经和面试题宝典
